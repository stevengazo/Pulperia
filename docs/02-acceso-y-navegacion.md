# 2. Acceso y navegación

## 2.1 Iniciar sesión

Al abrir el sistema se muestra la pantalla de acceso (`/login`).

1. Escribe tu **Correo electrónico**.
2. Escribe tu **Contraseña**.
3. (Opcional) Marca **Mantener la sesión abierta** si usas un equipo de confianza y no quieres volver a ingresar cada vez.
4. Presiona **Ingresar al sistema**.

Si los datos son correctos, entrarás al **Dashboard**. Si no:

- *"Email y contraseña son obligatorios"* → dejaste un campo vacío.
- *"Credenciales inválidas"* → el correo o la contraseña no coinciden.
- *"No se pudo conectar con el servidor"* → problema de conexión; vuelve a intentar en unos segundos.

> 🔑 **¿Olvidaste tu contraseña?** Las cuentas las gestiona el administrador del sistema. Contáctalo para restablecerla.

## 2.2 Cerrar sesión

En la parte inferior del menú lateral aparece tu **correo** y un botón **Cerrar sesión**. Al presionarlo, saldrás del sistema y volverás a la pantalla de acceso.

## 2.3 El menú lateral

El menú de la izquierda te lleva a cada pantalla:

| Grupo | Opción | Para qué sirve |
|-------|--------|----------------|
| Principal | **Dashboard** | Ver estadísticas generales |
| Principal | **Ventas** | Historial de ventas |
| Principal | **Nueva Venta** | Registrar y cobrar una venta |
| Gestión | **Productos** | Catálogo de productos |
| Gestión | **Inventario** | Compras y existencias |
| Gestión | **Empleados** | Lista e historial de empleados |
| Sistema | **Configuración** | Categorías, proveedores y permisos |
| Sistema | **Logs** | Auditoría de cambios |

Al final del menú hay un botón grande **NUEVA VENTA** como acceso rápido.

## 2.4 La barra superior

Siempre visible en la parte de arriba:

- **🔍 Buscador global:** escribe el nombre de un producto, empleado o venta y aparecerá un menú con los resultados; haz clic en uno para ir directo a él.
- **☀️ / 🌙 Botón de tema:** cambia entre modo diurno y nocturno (ver abajo).
- **🛒 Generar Venta:** acceso directo para registrar una venta.

## 2.5 Modo diurno y nocturno

PulpePOS tiene dos temas visuales:

- 🌙 **Modo nocturno (oscuro):** fondo oscuro, ideal con poca luz. Es el predeterminado.
- ☀️ **Modo diurno (claro):** fondo claro, ideal con mucha luz ambiental.

Para cambiar de tema, presiona el **botón de sol/luna** en la barra superior:

- Si ves un **sol** ☀️, estás en modo oscuro y al presionar pasarás a modo claro.
- Si ves una **luna** 🌙, estás en modo claro y al presionar pasarás a modo oscuro.

> 💡 Tu preferencia se **guarda automáticamente** en el navegador. La próxima vez que entres, el sistema recordará el tema que elegiste, sin parpadeos al cargar.
