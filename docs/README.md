## Un vistazo rápido

PulpePOS se organiza en un **menú lateral** con tres áreas:

- **Principal** — Dashboard, Ventas y Nueva Venta.
- **Gestión** — Productos, Inventario y Empleados.
- **Sistema** — Configuración y Logs.

En la parte superior (barra superior) siempre tienes disponibles:

- 🔍 Un **buscador global**.
- ☀️/🌙 El **botón de tema** (modo diurno/nocturno).
- 🛒 Un acceso directo a **Generar Venta**.

---

## Convenciones de este manual

- **Negrita** = nombre de un botón, campo o pantalla.
- 🟢🔴🟡 = colores usados en la aplicación para indicar estado.
- Los montos se muestran en **colones costarricenses (₡)**.
- Las rutas de cada pantalla se indican como `/productos`, `/ventas`, etc. (lo que aparece al final de la dirección en el navegador).
