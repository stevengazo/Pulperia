# 11. Glosario

Términos usados en PulpePOS y en este manual.

| Término | Significado |
|---------|-------------|
| **Auditoría** | Registro automático de los cambios hechos en el sistema. Ver [Logs](09-logs.md). |
| **Carrito** | Lista de productos que se están agregando a una venta antes de cobrarla. |
| **Categoría** | Clasificación de productos (Abarrotes, Bebidas, etc.). |
| **Cobrar** | Confirmar y registrar una venta, aplicando el pago y descontando stock. |
| **Compra** | Ingreso de mercadería desde un proveedor; aumenta el stock. |
| **Costo (Precio de costo)** | Lo que te cuesta adquirir un producto. |
| **CSV** | Formato de archivo de texto para tablas, se abre en Excel. |
| **Dashboard** | Pantalla principal con estadísticas del negocio. |
| **Devolución a proveedor** | Salida de mercadería que se regresa al proveedor; disminuye el stock. |
| **Fiado** | Venta a crédito, pendiente de pago. |
| **Folio** | Número que identifica una venta. |
| **Ganancia** | Diferencia entre lo vendido y lo que costó (ventas − compras / precio venta − costo). |
| **Incremento de inventario** | Suma manual de unidades al stock, sin registrar una compra. |
| **Inventario** | Conjunto de existencias y el registro de compras. |
| **Log** | Cada entrada del registro de auditoría. |
| **Método de pago** | Forma en que se paga: Efectivo, SINPE, Tarjeta o Fiado. |
| **Modo diurno / nocturno** | Temas visuales claro y oscuro de la aplicación. |
| **Presentación** | Formato o medida del producto (ej. "1 kg", "350 ml"). |
| **Proveedor** | Empresa o persona a quien le compras mercadería. |
| **Recibo / Ticket** | Comprobante de una venta, imprimible. |
| **SINPE** | Sistema de pago móvil costarricense. |
| **SKU** | Código o número interno que identifica un producto. |
| **Stock** | Unidades disponibles de un producto. |
| **Stock mínimo** | Nivel de alerta; por debajo de él, el producto se marca como "bajo stock". |
| **Venta** | Salida de mercadería a un cliente; disminuye el stock. |
